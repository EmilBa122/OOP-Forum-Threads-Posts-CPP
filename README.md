# OOP Forum Threads Posts CPP

## Assignment Description
Simulating an Online Forum in C++ using Object-Oriented Programming, i.e. using Classes for Forums, Threads and Posts.

- **Exercise 1:** Building the forum with its threads and posts, which print messages when they are created and destroyed and printing the forum's thread titles as well as a selected thread or post
- **Exercise 2:** Extending the forum with a function that prints all posts sorted in ascending order by creator using a binary search tree.

## In this repo the folders are organized as follows:

- **EXERCISE1** contains everything that corresponds to **Exercise 1** of the assignment
- **EXERCISE2** contains everything that corresponds to **Exercise 2** of the assignment
